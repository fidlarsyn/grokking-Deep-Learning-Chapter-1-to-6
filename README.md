**Bab 1: Introducing Deep Learning: Why You Should Learn It**
Mengenalkan konsep dasar *deep learning* sebagai bagian dari otomatisasi kecerdasan dan otomatisasi tugas-tugas industri. Bab ini menegaskan bahwa buku dirancang dengan tingkat kesulitan matematis yang rendah tanpa mengasumsikan latar belakang kalkulus atau aljabar linier perguruan tinggi.

**Bab 2: Fundamental Concepts: How Do Machines Learn?**
Membedakan model **supervised learning** (memprediksi satu dataset dari dataset lain) dan **unsupervised learning** (pengelompokan data/*clustering*). Selain itu, dibahas perbedaan model **parametric** (jumlah parameter tetap) vs **nonparametric** (parameter fleksibel mengikuti data), serta pengenalan awal alur kerja *"predict, compare, learn"*.

**Bab 3: Introduction to Neural Prediction: Forward Propagation**
Menjelaskan elemen dasar nodus (*nodes*) dan bobot (*weights*). Menguraikan cara jaringan saraf melakukan prediksi dengan masukan tunggal, *multiple inputs*, *multiple outputs*, hingga *multiple inputs &amp; outputs*, serta penggunaan operasi perkalian titik (*dot product*) menggunakan NumPy.

**Bab 4: Introduction to Neural Learning: Gradient Descent**
Mengukur eror menggunakan *Mean Squared Error*. Mengajarkan metode pengubahan bobot sederhana (*hot and cold learning*) hingga algoritma **gradient descent** berbasis turunan (*derivatives*) untuk mengarahkan penurunan eror ke angka nol. Memperkenalkan parameter **alpha** (*learning rate*) untuk mencegah overkoreksi (*divergence*).

**Bab 5: Learning Multiple Weights at a Time: Generalizing Gradient Descent**
Menganalisis pengaruh pembaruan bobot ketika salah satu bobot dibekukan (*freezing weights*). Mengaplikasikan algoritma *gradient descent* pada dataset riil pertama, yaitu pengenalan angka tulisan tangan **MNIST**.

**Bab 6: Building Your First Deep Neural Network: Introduction to Backpropagation**
Membangun jaringan saraf tiruan berlapis (*deep neural network*) pertama dan memecahkan masalah atribusi eror jarak jauh melalui **backpropagation**.
